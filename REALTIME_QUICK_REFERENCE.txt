🔧 HOOK USAGE
─────────────────────────────────────────────────────────────────────────────

import { useAnalyticsRealtime } from "@/hooks/useAnalyticsRealtime";

export function Dashboard() {
  const {
    metrics,        // { totalRevenue, premiumRevenue, ... }
    chartData,      // Array for charts
    isLoading,      // Boolean
    error,          // Error message or null
    lastUpdate,     // Date object
    refresh,        // Function to manually refresh
    isSubscribed,   // Real-time connection status
  } = useAnalyticsRealtime({
    dateRange: 30,      // 30 or 90 days
    autoSubscribe: true // Auto-connect on mount
  });
}

❌ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Dashboard not updating?
  1. Check "Live" badge → should be green
  2. Browser DevTools → Console → check for errors
  3. Supabase Dashboard → Database → Replication → check toggles
  4. Verify RLS policies don't block admin user

Analytics shows zero?
  1. Supabase Dashboard → SQL Editor → Run test insert
  2. Check payment_orders has data with payment_status = 'paid'
  3. Verify date range filter (30 vs 90 days)

Query errors?
  1. Check PostgreSQL syntax in SQL script
  2. Verify trigger function exists
  3. Run verification queries from ANALYTICS_DATA_STRUCTURE.md

See detailed guide: REALTIME_ANALYTICS_SETUP.md → Troubleshooting
